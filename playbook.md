# Playbook

- In non-interactive shells, `nvm` may not be sourced even when Node is available. Verify `node --version` first; source `$NVM_DIR/nvm.sh` only when version switching is required.
- For multi-file text replacements, validate and apply each independent replacement atomically. A missing later match must not leave the preceding replacements in an ambiguous partially updated state.
- If a configured subagent is unavailable, record the unavailable agent ID and continue with local review/build checks rather than repeatedly retrying the same delegation.
- HTML pages and Markdown pages are parsed differently by blog-engine-md. Keep complex inline `<style>` and module scripts in an `.html` source page; embedding them in Markdown can corrupt CSS during rendering.
- During a multi-step migration, do not delete temporary recovery inputs until the final build passes. When a tracked source was overwritten, recover it directly from `git show HEAD:<path>`.
- Refreshing `wire-diagram` must copy every `dist/*.js` chunk, not only `wire-diagram.js` and the 3D helpers. The ESM entry now re-exports from a hashed `index-*.js`; without that sibling, YAML `number`/`gpio` fields will not parse or render.
- When asserting that UI copy was removed, strip `<script>` tags from Chrome `--dump-dom` output first. Leftover strings in JS comments otherwise look like a failed removal.
- `current` can be a broken symlink. Repo-wide ripgrep then aborts; search `content/` or another real directory instead of the repo root.
- `/docs/` is auto-listed unless `content/docs/index.html` exists. For a designed hub, ship an HTML index with `hideToc` and no `showChildren`, and keep internal runbooks out of `content/docs/`.
- Entrance Observer lab wiring must use builtin `kind: jetson-orin-nano`, not a host `kind: jetson`. Leave POWER/USB3/ETH/DP without `pin.position` so 3D wires land on the library ports. Unqualified `jetson.GND` is header pin 6, not the barrel; official Orin Nano kit power is the 19 V DC barrel, USB-C is data/recovery only, and video is DisplayPort.
- Lab product wiring is electrical interconnect only. Do not put 2020 extrusion, camera mount, or other mechanical joints on the schematic, table, or BOM map; those stay on the Phase 1 Lab BOM.
- To assert Jetson 3D pin alignment in Node, import the vendored `view3d-*.js` chunk first. Builtin resolvers register on that lazy import; `localPinPosition` from the ESM entry alone falls back to schematic edge slots.
- Entrance Observer lab wiring belongs on the product HTML page (`entrance-observer.html` at `/docs/entrance-observer/#wiring-diagram`), same pattern as Beehive sensors. Keep the old phase-1 wiring URL as a `redirectUrl` stub.
- `blog-engine serve` can rebuild in a loop if `content/embeddings.json` is rewritten while watched. Stop the server after verification and do not commit that file. Do not run `just build` / `rm -rf dist` while serve is still writing; the delete fails with Directory not empty and homepage requests 404 mid-rebuild.
- Headless Chrome `--screenshot` / `--dump-dom` against that live serve can capture the mid-rebuild 404. Assert copy from a finished `curl` (strip `<script>` first) or from `dist/` after the rebuild completes, not from a screenshot taken while embeddings.json is still triggering rebuilds.
- Later `.front-page .front-section { max-width: 1100px }` overrides an earlier `.front-section--app` wider rule at the same specificity. Put the wider exception after the base section rule.
- Homepage feature cards that are `<a>` inherit `main a:hover` yellow fill. Override background and `color: inherit !important` on `.feature` and download badge links.
- Legacy case-sensitive URLs (for example `/research/Datasets/`) need a separate `redirectUrl` stub with an explicit `slug: Datasets`. blog-engine lowercases generated slugs, so the main page stays at `/research/datasets/`. On case-insensitive macOS builds, `datasets/` and `Datasets/` collide in `dist/`; verify redirect stubs on Linux production or by URL path case, not only by local `dist` layout.
- A curl during a live rebuild can 404 a localized `/ru/` page that already exists in the finished `dist`. Recheck after the rebuild completes.
- Self-hosted fonts referenced as `/assets/css/...` must not live under `content/assets/css/` unless blog-engine strips the duplicate `assets/` segment on copy. Otherwise they deploy to `/assets/assets/css/...` and `@font-face` 404s while CSS still lists Scada. Verify with `curl -sI https://gratheon.com/assets/css/Scada/Scada-Regular.ttf` or put fonts under `content/css/`.
- The Gratheon workspace root contains separate repositories; run website git commands from `gratheon.com/`, not the workspace root.
- Literature discovery must tolerate null OpenAlex titles and API rate limits. Cache responses, normalize missing fields, and use other scholarly indexes when Semantic Scholar returns HTTP 429; do not interpret an unavailable API as no results.
- On 2026-09-24, `dev-code-reviewer-quick` could not start because its Docker health check reported `openrouter_usage_limit_reached` (HTTP 503). Continue with independent local metadata/PDF checks rather than retrying that agent.
- Indexed `content_search` is disabled for this project; use scoped grep or a local parsed inventory. A PDF endpoint can return HTTP 200 with an HTML challenge: verify `%PDF-`, parseability, and article identity before copying. Public arXiv access does not itself grant redistribution rights; keep source PDF links when no reuse license is stated, and do not mirror NC-licensed PDFs onto a commercial product site without permission.
- Concurrent research sessions can add papers during validation. Track this session's explicit file manifest rather than treating every post-inventory file as yours. Generate commit indexes from an isolated HEAD-plus-owned-papers snapshot and stage those blobs, leaving other sessions' working files untouched.
- Use NUL-delimited `git ls-tree -rz --name-only` output for snapshot manifests; default Git quoting hides Unicode paper filenames from path-prefix filters. Mark PDF assets as binary in `.gitattributes`: valid ASCII-heavy PDFs can otherwise trigger text whitespace checks. Never rewrite a source PDF to satisfy text formatting checks.
- Research curation supplement (2026-09-24): preflight the complete output manifest before writing, then recheck each path immediately before creation. Concurrent additions can invalidate the initial duplicate inventory. Verify survey pagination against both Crossref and PDF footers; do not infer page ranges from PDF page counts.
- Call `suggest_session` and `suggest_git_commit` as top-level tools after completing the work; the parallel dispatcher rejects action-card tools and may skip the whole batch.
