Comme solution plus rentable pour les grands ruchers, nous voulons réutiliser les fonctionnalités de la [ruche robotisée](/fr/products/robotic_beehive/) et lui ajouter la capacité de se déplacer dans le rucher afin d’inspecter les ruches à la demande ou selon un planning.

### Problèmes ciblés
Parmi les problèmes apicoles, ce produit aide particulièrement à traiter :
- l’effondrement hivernal ;
- les emplacements éloignés ;
- la pollinisation précise ;
- les ruchers multiples ;
- l’observabilité de la colonie ;
- le travail difficile à mettre à l’échelle.

### Public cible
- Apiculteurs industriels
- Agriculteurs

## Défis / exigences
- Inspecter plusieurs ruches (environ 10) avec les mêmes fonctions que la [ruche robotisée](/fr/products/robotic_beehive/)
- Rester rentable grâce à un seul module mobile
- Prendre une forme mobile ou remorquable : l’objectif est de pouvoir déplacer l’ensemble du rucher en voiture et de ramener les ruches à la base pour l’hiver, sans dépendre d’un grand conteneur

# Vision

Nous utiliserons une amélioration de la [ruche robotisée](/fr/products/robotic_beehive/) avec une capacité de déplacement **entre les ruches**. La conception n’est pas encore arrêtée et l’architecture reste à décider par l’équipe.

# Idéation

### Déplacement

|      | Déplacement sur rails | Déplacement sur roues |
| ---- | --------------------- | --------------------- |
| Avantages | Mouvement simple et prévisible | Les positions des ruches peuvent être irrégulières |
| Inconvénients | Portée limitée ; les ruches doivent être alignées ; coût supérieur pour les grands ruchers | Besoin de stabiliser les angles X-Y pour garder un plan horizontal |

## Construction

|      | Monolithique | Distribuée |
| ---- | ------------ | ---------- |
| Avantages | Installation, maintenance et configuration plus simples ; bonne protection météo | Peut évoluer en nombre de ruches et en hauteur ; plus rentable ; séparation plus saine des colonies |
| Inconvénients | Les colonies peuvent se contaminer mutuellement ; coût plus élevé ; perte d’inventaire existant | Intégration et maintenance plus complexes |
