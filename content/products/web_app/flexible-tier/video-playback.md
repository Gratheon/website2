## Goal

Beekeeper should be able to playback the video recording of the specific beehive entrance recorder by by [Video streaming via API](../../entrance_observer/features/🎥%20Video%20streaming%20via%20API.md), [Video streaming from phone](../pro-tier/video-streaming-from-phone.md) features.

Goal is to reduce beekeeper reaction time in case of [Hornet attack detection](../../entrance_observer/todo/🚁%20Hornet%20attack%20detection.md), [Robbing state](../../../about/problems/biological/💢%20Robbing%20state.md)

## User story

Beekeeper

- Creates a beehive with a hive entrance
- Installs a device on a hive - [Device management](../future-ideas/pro-tier-ideas/device-management.md)
    - Generates API token - [API token management](../free-tier/api-token-management.md)
- Enters API token into the device and starts streaming
- Clicks on hive entrance
- Sees lists of video streams
