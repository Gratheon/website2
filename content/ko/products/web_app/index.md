Gratheon 웹 앱은 양봉가가 [양봉장 데이터](/products/web_app/free-tier/apiary-management/)를 관리하고, 설치된 모듈형 벌통 장치와 통신하며, 소비 및 바닥판 이미지를 분석하고, [시계열 원격 측정](/products/web_app/pro-tier/hive-telemetry-storage/)을 저장하며, [알림](/products/web_app/flexible-tier/alerts/)과 AI 제안을 통해 문제 해결을 돕도록 설계되었습니다.

`status`: [TRL 6](https://www.nasa.gov/directorates/somd/space-communications-navigation-program/technology-readiness-levels/)

## 핵심 기능

웹 앱은 다음을 하나의 시스템으로 연결합니다.

- 양봉장과 벌통 관리
- 점검 기록과 사진 이력
- IoT 장치의 원격 측정 데이터
- Entrance Observer의 영상과 입구 활동 지표
- 알림, 비교 분석, AI 기반 의사결정 지원

이는 [Entrance Observer](../entrance_observer/entrance_observer.md), [🌡️ 벌통 저울](../scales/scales.md), 향후 로봇 제품이 연결되는 Gratheon의 중심 제품입니다.

## 주요 사용 사례

### 사진 업로드로 봉군 상태 파악

- 벌통을 생성합니다.
- 상자와 소비를 추가합니다.
- 벌과 벌집 셀이 보이는 소비 사진을 업로드합니다.
- 백엔드 처리를 기다립니다.
- 벌 수와 셀 분포에 대한 AI 기반 통계를 받습니다.

### 봉군 발달 추적

- 각 점검을 벌통 상태의 스냅샷으로 저장합니다.
- 시간에 따라 자원 분포가 어떻게 달라지는지 확인합니다.
- 기억이 아닌 데이터에 기반해 급이, 처리, 분봉 또는 대기를 결정합니다.

### IoT 센서 원격 측정 수신

- 계정 설정에서 API 토큰을 생성합니다.
- 벌통 센서 장치를 Wi‑Fi에 연결합니다.
- 무게, 온도, 습도와 같은 데이터를 앱으로 전송합니다.
- 그래프와 분석 화면에서 추세를 확인합니다.

### 입구 영상 스트리밍

- [Entrance Observer](../entrance_observer/entrance_observer.md)를 설정합니다.
- 비디오 스트림이 표시되는지 확인합니다.
- 활동량, 도봉, 분봉 징후 등을 해석하기 위해 지표와 알림을 사용합니다.

### 바닥판으로 Varroa 모니터링

- 벌통에 바닥판 섹션을 추가합니다.
- Varroa 진드기가 보이는 흰색 슬라이드 패널 사진을 업로드합니다.
- 이미지는 점검 기록과 함께 버전 관리됩니다.
- 바닥판 Varroa 계수 기능은 감염 수준과 처리 결정을 평가하는 데 도움을 줍니다.
