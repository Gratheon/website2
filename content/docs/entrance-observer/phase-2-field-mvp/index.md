Phase 2 is the first outdoor pilot build. It keeps the Jetson reference platform unless a measured Raspberry Pi + Hailo prototype is ready, but it changes the product from a desk setup into a weather-protected, serviceable hive-entrance observer.

## Pages in this phase

- [Product description](product-description.md) - outdoor architecture, operating modes, installation rules, and acceptance criteria.
- [Bill of materials](bill-of-materials.md) - weatherproof field kit parts and alternatives.

## Phase outcome

A pilot beekeeper can install one entrance camera on a hive, receive direction-aware bee traffic telemetry in Gratheon, request a live view only when needed, and keep the device serviceable after rain, heat, weak WiFi, and temporary network outages.
