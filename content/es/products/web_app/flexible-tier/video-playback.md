## Objetivo

El apicultor debe poder reproducir la grabación de vídeo de una cámara instalada en una piquera concreta mediante las funciones [transmisión de vídeo por API](/products/entrance_observer/features/🎥%20Video%20streaming%20via%20API/) y [transmisión de vídeo desde el teléfono](/products/web_app/pro-tier/video-streaming-from-phone/).

El objetivo es reducir el tiempo de reacción del apicultor ante casos como [detección de ataque de avispones](/products/entrance_observer/todo/🚁%20Hornet%20attack%20detection/) o [estado de pillaje](/about/problems/biological/💢%20Robbing%20state/).

## Historia de usuario

Apicultor:

- Crea una colmena con una piquera.
- Instala un dispositivo en la colmena - [gestión de dispositivos](/products/web_app/future-ideas/pro-tier-ideas/device-management/).
  - Genera un token de API - [gestión de tokens de API](/es/products/web_app/free-tier/api-token-management/).
- Introduce el token de API en el dispositivo e inicia la transmisión.
- Hace clic en la piquera.
- Ve la lista de transmisiones de vídeo disponibles.
