### 🎯 Propósito

Permitir que nuevos apicultores creen una cuenta en Gratheon y comiencen a registrar apiarios, colmenas, dispositivos y datos de inspección.

### 🎭 Historia de usuario

- Como nuevo usuario,
- quiero registrarme con mi correo y contraseña,
- para empezar a gestionar mis colmenas en la plataforma.

### 🚀 Beneficios clave

- **Entrada sencilla**: creación de cuenta con datos mínimos.
- **Preferencia de idioma**: detección o selección de idioma desde el inicio.
- **Base para datos propios**: perfil asociado a apiarios, colmenas y sensores.
- **Acceso a planes**: punto de partida para funciones gratuitas y premium.

### 🔧 Resumen técnico

El registro crea un perfil de usuario, almacena credenciales de forma segura y prepara la cuenta para preferencias, facturación, tokens de API y recursos de apicultura.

### 📋 Criterios de aceptación

- Formulario de registro con email y contraseña.
- Validación de email y requisitos de contraseña.
- Creación segura del usuario.
- Aplicación de idioma detectado o seleccionado.
- Redirección a la aplicación tras registro correcto.
- Mensajes claros para errores como email ya usado.

### 🚫 Fuera de alcance

- Registro empresarial con varios usuarios.
- Importación masiva inicial de colmenas.
- Verificación avanzada de identidad.
