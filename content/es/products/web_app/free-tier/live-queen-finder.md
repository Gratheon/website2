Live Queen Finder usa visión por computador para ayudar a localizar la reina en fotos o vídeo de cuadros. El objetivo es reducir el tiempo de búsqueda durante inspecciones y hacer que las revisiones sean menos invasivas para la colonia.

## Qué resuelve

- Menos tiempo con la colmena abierta.
- Menos estrés para abejas y apicultores.
- Mejor documentación de dónde se vio la reina durante una inspección.
- Base para funciones posteriores de seguimiento de reina y salud de colonia.

## Flujo de trabajo

1. El apicultor sube una imagen o vídeo corto de un cuadro.
2. La aplicación procesa el archivo con un modelo de detección.
3. Las posibles ubicaciones de la reina se resaltan para revisión humana.
4. El resultado puede guardarse junto con la inspección.

## Estado

Esta función forma parte del plan gratuito para hacer útil la aplicación desde el primer día. La precisión depende de la calidad de imagen, iluminación, densidad de abejas y aspecto de la reina.
