### 🎯 Zweck
QR-Codes helfen, eine physische Beute, ein Honigglas oder eine öffentliche Beutenansicht schnell mit dem passenden digitalen Datensatz zu verbinden.

### 🎭 Nutzergeschichte
- Als Imker mit vielen Beuten
- möchte ich QR-Codes erzeugen und ausdrucken,
- damit ich im Feld schnell die richtige Beute öffne oder eine öffentliche Ansicht teilen kann.

### 💡 Anwendungsfälle
- **Beutenetiketten**: Code an der Beute scannen und direkt den Beutendatensatz öffnen.
- **Öffentliche Ansicht**: Besucher oder Kunden scannen den Code und sehen freigegebene Informationen.
- **Honigglas-Marketing**: Ein QR-Code kann auf eine Geschichte zur Herkunft oder zum Bienenstand verweisen.
- **Große Bienenstände**: Bei vielen ähnlich aussehenden Beuten reduziert ein Code Suchaufwand und Verwechslungen.

### 🧭 Vorgeschlagene Lösung
- Beim Erzeugen einer öffentlichen Beuten- oder Durchsichts-URL wird zusätzlich ein QR-Code erstellt.
- Der Code kann als Bild gespeichert oder gedruckt werden.
- Optional werden Beutenname, Nummer oder Farbe in das Etikett integriert.
- Der Link kann auf die [öffentliche Beutenansicht](/de/products/web_app/free-tier/public-beehive-view/) zeigen.

### 📎 Asset-Wiederverwendung
Falls Screenshots oder Beispiele benötigt werden, sollen sie aus den gemeinsamen englischen Produkt-Assets referenziert werden, z. B. `/products/web_app/free-tier/img/...`, statt sie in den deutschen Ordner zu kopieren.
