# Поддержка клавиатуры — техническая документация

### 🎯 Обзор
Поддержка клавиатуры обеспечивает более быструю навигацию и действия в web-app с помощью контекстно-зависимых ярлыков. Доступные сочетания клавиш адаптируются к текущему экрану, а подсказки клавиатуры отображаются в пользовательском интерфейсе, помогая пользователям быстро находить и изучать действия.

### ✅ Ключевые модели поведения
- **Сочетания клавиш, зависящие от контекста**: для текущего или модального представления активны только соответствующие комбинации клавиш.
- **Видимые подсказки клавиатуры**: пользовательский интерфейс отображает подсказки по сочетаниям клавиш, чтобы пользователи могли находить действия, не выходя из рабочего процесса.
- **Последовательность действий для опытных пользователей**: стандартные операции можно выполнять без переключения между клавиатурой и мышью.
