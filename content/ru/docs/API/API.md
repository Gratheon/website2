Давайте настроим ваши устройства ульев для взаимодействия с Gratheon!

Здесь также можно увидеть, как именно мы обрабатываем эти данные: архитектуру, сервисы, код и причины выбора одного решения вместо другого. Если вы достаточно технически подкованы и находите эти материалы полезными, улучшайте эти руководства на GitHub или добавляйте новые.

Мы предоставляем [REST](rest/index.md) для устройств и [GraphQL](GraphQL.md) для программных интеграций, которые могут быстрее адаптироваться к breaking changes.
