Фаза 2 — первая outdoor pilot сборка. Она сохраняет Jetson reference platform, если measured Raspberry Pi + Hailo prototype ещё не готов, но переводит продукт из desk setup в weather-protected, serviceable hive-entrance observer.

## Страницы этой фазы

- [Описание продукта](product-description.md) — outdoor architecture, operating modes, installation rules и acceptance criteria.
- [Bill of materials](bill-of-materials.md) — детали field kit, weatherproofing и alternatives.

## Результат фазы

Pilot beekeeper может установить одну entrance camera на улей, получать direction-aware bee traffic telemetry в Gratheon, запрашивать live view только когда нужно и обслуживать устройство после дождя, жары, слабого WiFi и временных network outages.
