Веб-приложение Gratheon предназначено для помощи пчеловодам в управлении [данными пасеки](free-tier/apiary-management.md), взаимодействии с установленными модульными устройствами улья, анализе фотографий рамок и нижнего летка, хранении [телеметрии временных рядов](pro-tier/hive-telemetry-storage.md), генерации [оповещений](flexible-tier/alerts.md), прогнозировании и предоставлении рекомендаций ИИ для решения проблем.

`status`: [TRL 6](https://www.nasa.gov/directorates/somd/space-communications-navigation-program/technology-readiness-levels/)

## Основные сущности домена

| Сущность | Описание | Ключевые свойства |
|--------|-------------|----------------|
| **Пасека** | Набор ульев, расположенных вместе в определённом месте. Размер ограничен окружающей территорией, которую могут опылять пчёлы | Расположение (широта/долгота), название, активный статус |
| **Улей** | Физическая конструкция улья с вертикальными секциями. Может быть разделён, объединён или сложен | Название, цвет, статус, коробки, семья, история разделений/объединений, отслеживание складывания |
| **Семья (Колония/Матка)** | Сверхорганизм пчёл под руководством матки, откладывающей яйца | Порода (variations apis mellifera), год добавления, возраст (автоматический расчёт), обработки |
| **Коробка (Секция улья)** | Полый деревянный section, содержащий рамки. Типы: Мажковый (расплошная), Медовый, Леток, Вентиляция, Обрамляющая решётка, Горизонтальная подкормка, Нижний леток | Тип, позиция, цвет, рамки |
| **Рамка** | Деревянная рамка с восковым фундаментом внутри секций. Типы: Фундамент, Пустая сота, Пустота, Перегородка, Подкормка | Тип, позиция, левая/правая стороны |
| **Сторона рамки** | Одна сторона рамки, куда можно загружать фотографии для анализа ИИ | Ссылки на файлы изображений, обнаруженные ресурсы |
