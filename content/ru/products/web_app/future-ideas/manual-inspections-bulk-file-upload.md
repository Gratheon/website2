## Пользовательская история - добавление файлов

- Пользователь открывает просмотр секции улья.
- Пользователь видит блок, область или кнопку массовой загрузки, похожую на [загрузку фото стороны рамки](../../../docs/web-app/features/frame-photo-upload.md).
- Пользователь перетаскивает 12 файлов со своего компьютера.
  - Если пользователь выбрал больше файлов, чем есть сторон рамок, лишние файлы игнорируются, но сверху показывается предупреждение со списком имён файлов, которые были проигнорированы.
  - Если список проигнорированных файлов длиннее 3 элементов, добавить `...` в конце и не показывать остальные.
- Файлы загружаются по одному.
  - По возможности показывать прогресс хотя бы по количеству файлов, например `Загружено 3 из 12 файлов`.
- Файлы назначаются сторонам рамок, начиная **слева направо →**.
- Компонент загрузки должен позволять пользователю переходить в другие разделы без отмены загрузки.
- Когда все файлы загружены, показать сообщение об успехе: `Загрузка завершена`.
