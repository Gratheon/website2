## Пользовательская история

- Пчеловод загружает фото рамки улья - [Загрузка фото стороны рамки](../../../docs/web-app/features/frame-photo-upload.md)
    
- Приложение выполняет распознавание:
    
    - [Распознавание рабочих пчёл](worker-bee-detection.md)
    - [Распознавание трутней](../future-ideas/pro-tier-ideas/drone-detection.md)
    - [Распознавание матки](queen-detection.md)
- Приложение обновляет вид стороны рамки улья и показывает количество обнаруженных пчёл, например `Рабочие пчёлы (120)`
    ![](/products/web_app/hobbyist-tier/img/screenshot-2024-07-10-at-21-04-24.png)
    
    
- Приложение обновляет вид улья и показывает общее количество пчёл
    
    ![](/products/web_app/hobbyist-tier/img/screenshot-2024-07-10-at-21-02-31.png)
    
- Приложение обновляет список пасек и показывает общее количество пчёл по каждому улью
