## Создание осмотра

- Пчеловод вручную осмотрел улей и сделал фотографии.
- Пользователь создал улей с корпусами и загрузил фото рамок.
- Некоторое время, например две недели, он ничего не менял. Теперь прошёл новый осмотр, и старое состояние нужно сохранить.
- Пользователь нажимает `Create Inspection`:
  - все данные улья сохраняются как снимок во времени;
  - время осмотра берётся из самого старого **времени создания фото рамки**, а не из текущего времени;
  - поэтому может быть создан осмотр двухнедельной давности.
- Фотографии рамок **отвязываются/очищаются** вместе с найденными объектами.
- Статистика ячеек рамки очищается; см. [распознавание и управление ячейками сота](/products/web_app/starter-tier/honeycomb-cell-detection-and-management/).
- Рамки снова становятся пустыми, и пользователь может загрузить новые фотографии.
- Показывается сообщение `Inspection created`.
- Ссылка на timeline осмотров появляется рядом с меню и количеством осмотров.

## Список осмотров

- Пользователь переходит к списку осмотров улья, например `https://app.gratheon.com/apiaries/7/hives/118/inspections`.
- Пользователь видит список осмотров с датами.
- По клику на осмотр открываются детали.

## Просмотр осмотра

- Пользователь видит рамки и статистику ячеек.
- Пользователь видит фотографии рамок, связанные с этим осмотром.
- Осмотр можно использовать для сравнения состояния семьи между сезонами, обработками и событиями на пасеке.
