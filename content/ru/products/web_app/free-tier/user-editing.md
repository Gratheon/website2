### 🎯 Назначение

Обновляйте данные аккаунта, меняйте языковые настройки и управляйте параметрами безопасности на одной странице аккаунта.

### 🎭 Пользовательская история

- Как зарегистрированный пользователь-пчеловод,
- я хочу обновлять данные аккаунта и предпочтения,
- чтобы профиль оставался актуальным, а интерфейс соответствовал моим рабочим привычкам.

### 🚀 Ключевые преимущества

- **Централизованные настройки**: все параметры аккаунта собраны в одном месте.
- **Мгновенная смена языка**: язык интерфейса меняется сразу после выбора.
- **Контроль безопасности**: пароль можно обновить в любой момент.
- **Управление email**: контактный адрес используется для уведомлений и важных оповещений по ульям.
- **Настройки приватности**: пользователь управляет тем, какая информация хранится и используется.

### 💡 Сценарии

**Смена языка интерфейса**  
Если удобнее работать на родном языке, пользователь может переключиться с английского на русский, украинский, эстонский или другой поддерживаемый язык.

**Обновление пароля**  
Пользователь регулярно меняет пароль для безопасности или обновляет его при подозрении на несанкционированный доступ.

**Смена контактного email**  
При смене почтового сервиса пользователь обновляет email, чтобы продолжать получать важные оповещения об ульях.

**Настройка предпочтений**  
Пользователь настраивает уведомления, единицы измерения, формат даты и другие параметры под свой рабочий процесс.

### 🎓 Как пользоваться

1. **Откройте настройки аккаунта** - перейдите на [app.gratheon.com/account](https://app.gratheon.com/account).
2. **Измените поля** - выберите email, имя, язык или другой параметр, который нужно обновить.
3. **Смените пароль** - для смены пароля сначала введите текущий пароль.
4. **Сохраните изменения** - нажмите кнопку «Сохранить».
5. **Проверьте подтверждение** - после успешного сохранения появится сообщение о результате.

#### ⚙️ Доступные настройки

**Информация профиля**

- Отображаемое имя
- Адрес email
- Предпочитаемый язык

**Безопасность**

- Смена пароля с подтверждением текущего пароля
- История входов, когда функция будет доступна

**Предпочтения**

- Язык интерфейса, который применяется сразу
- Настройки уведомлений
- Единицы измерения
- Формат даты и времени

### 🌍 Языки

Поддерживаемый список языков постепенно расширяется. Сейчас в интерфейсе используются те же языки, что и на сайте Gratheon, включая русский, эстонский, украинский, английский и другие локализации.

### 🔒 Заметки по безопасности

- Для смены пароля нужен текущий пароль.
- Смена email может потребовать подтверждения через письмо.
- О важных изменениях безопасности аккаунта пользователь получает уведомление.
