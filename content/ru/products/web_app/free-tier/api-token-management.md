### 🎯 Назначение

Позволяет пользователям создавать, просматривать и отзывать API-токены для безопасного доступа к сервисам Gratheon с внешних устройств и приложений.

### 🎭 Пользовательская история

- Как пчеловод с IoT-устройствами или собственными интеграциями,
- я хочу создавать и управлять API-токенами для своего оборудования,
- чтобы безопасно подключать Entrance Observer, датчики и другое оборудование к аккаунту Gratheon.

### 🚀 Ключевые преимущества

- **Безопасная аутентификация устройств**: bearer-токены для IoT-оборудования.
- **Управление жизненным циклом токенов**: создание, просмотр и отзыв по необходимости.
- **Несколько устройств**: отдельные токены для разных устройств или приложений.
- **Контроль безопасности**: отзыв скомпрометированного токена без влияния на остальные устройства.

### 🔧 Технический обзор

Система управления API-токенами с генерацией bearer-токенов для аутентификации устройств. Токены используют Entrance Observer, телеметрию и сервисы загрузки видео для доступа к API Gratheon без учётных данных пользователя.

### 📋 Критерии приёмки

- Интерфейс управления токенами в настройках аккаунта.
- Создание новых токенов с понятными названиями.
- Список существующих токенов с датами создания и статусом использования.
- Отзыв отдельных токенов с немедленным эффектом.
- Проверка токенов на всех защищённых API-эндпоинтах.
- Криптографически стойкая генерация токенов.
- Отслеживание использования и метка времени последнего применения.

### 🚫 Вне области

- Срок действия токенов (действуют до отзыва).
- Ограниченные права доступа (токен даёт полный доступ к аккаунту).
- Расширенная аналитика использования.
- Массовые операции с токенами.

### 🏗️ Подход к реализации

- **Frontend**: интерфейс управления токенами в настройках аккаунта.
- **Backend**: безопасная генерация с криптографическими библиотеками.
- **База данных**: хранение токенов с привязкой к пользователю и метаданными.
- **API**: проверка bearer-токенов на всех защищённых эндпоинтах.
- **Безопасность**: хеширование и безопасное хранение.

### 📊 Метрики успеха

- 100% успешность генерации токенов.
- >99% успешной аутентификации API для валидных токенов.
- Немедленный эффект отзыва токена.
- Нулевые инциденты несанкционированного доступа.
- Доля пользователей, подключивших устройства через токены.
