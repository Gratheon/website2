## Задачи и требования

- осматривать несколько, примерно 10, ульев с функциональностью [роботизированного улья](../robotic_beehive/robotic_beehive.md);
- быть экономичной: один перемещаемый модуль вместо робота на каждый улей;
- поддерживать мобильную форму трейлера, чтобы пасеку можно было перевозить автомобилем;
- позволять возвращать ульи на базу на зимовку без большого контейнера.

# Видение

Мы будем использовать улучшение [роботизированного улья](../robotic_beehive/robotic_beehive.md), но сделаем его **перемещаемым между ульями**. Архитектура пока не зафиксирована и должна быть выбрана командой.

# Идеация

## Перемещение

|      | Движение по рельсам | Движение на колёсах |
| ---- | ------------------- | ------------------- |
| Плюсы | простое и предсказуемое движение | ульи могут стоять произвольно |
| Минусы | ограниченный радиус; ульи должны стоять в линию; дороже на больших пасеках | нужно стабилизировать X-Y углы и удерживать горизонтальную плоскость |

## Конструкция

|      | Монолитная | Распределённая |
| ---- | ---------- | -------------- |
| Плюсы | простая установка, обслуживание и защита от погоды | масштабируется по количеству и высоте ульев; дешевле; лучше для здоровья семей |
| Минусы | семьи могут заражать друг друга; выше стоимость; потеря совместимости с текущим инвентарём | более сложная интеграция и обслуживание |
