## Обзор

Beemate - австралийское решение для наблюдения за летком, которое использует HD-камеру и AI для подсчёта пчёл. Также есть функции live streaming.

[https://blynk.io/clients/beemate-ai-powered-hives](https://blynk.io/clients/beemate-ai-powered-hives)

> uses a HD camera to count bees and run artificial intelligence software. It sends the data to our cloud platform

## Возможности продукта

- HD-камера у летка улья
- AI-подсчёт пчёл
- Прямая трансляция летка
- Воспроизведение видео
- Доступ через iOS, Android и веб-приложение
- Облачная платформа для хранения данных
- Мониторинг в реальном времени

## Конкурентный анализ

### Сильные стороны

- Live streaming как заметное уникальное предложение
- AI-подсчёт пчёл, похожий по направлению на Gratheon
- Поддержка нескольких платформ
- Присутствие на австралийском рынке
- Воспроизведение видео для исторического анализа
- Использование Blynk IoT platform ускоряет разработку

### Слабые стороны относительно Gratheon

- Ограничение австралийским рынком
- Предположительно менее сложные AI-модели
- Нет внутреннего осмотра рамок
- Меньшая компания и меньше финансирования
- Ограниченное присутствие в Европе

### Стратегические выводы

- Похожая концепция подтверждает подход Gratheon.
- Live streaming - привлекательная функция, которую стоит учитывать.
- Географическое разделение снижает прямую конкуренцию.
- Потенциальная цель для партнёрства или приобретения.
- Можно изучить их реализацию видеостриминга.
