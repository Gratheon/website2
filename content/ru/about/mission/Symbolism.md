## Уведомление о товарном знаке Gratheon™

Хотя наше программное обеспечение остается open source под лицензией AGPL (см. [Why open source](/ru/about/company/why-open-source/)), бренд и логотип Gratheon защищены товарными знаками.

**Gratheon™** является товарным знаком Gratheon OÜ, зарегистрированным в Эстонии Эстонским патентным ведомством под регистрационным номером **65350** и заявкой **M202501179**. Регистрация была выполнена 18 июня 2026 года и действует до 8 декабря 2035 года. Сертификат доступен как [Gratheon trademark certificate 65350](/assets/assets/legal/gratheon-trademark-certificate-65350.pdf).

Зарегистрированный изобразительный знак со словесным элементом охватывает классы Ниццкой классификации:
- **Класс 7:** промышленные роботы для работы с пчелиными семьями; автоматические подъемные механизмы для секций ульев; промышленные роботы для сельского хозяйства; механизированное оборудование для пчеловодства; роботизированные подъемные устройства для перемещения рамок.
- **Класс 9:** электронные устройства и приборы мониторинга пчелиных семей; весы для пчелиных семей; датчики температуры и влажности; видеокамеры для мониторинга летков; роботизированные устройства для осмотра ульев; загружаемые мобильные приложения для управления пчелиными семьями; загружаемое ПО для аналитики пчеловодства; IoT-датчики; приборы и инструменты для инспекции в пчеловодстве; электронные устройства обработки изображений для автоматической фотографии рамок; электрические устройства мониторинга и управления для отслеживания пчелиных семей.
- **Класс 42:** Software as a Service (SaaS) для управления и мониторинга пчелиных семей; облачные сервисы для хранения и анализа результатов пчеловодства; Platform as a Service (PaaS) для ПО управления пчелиными семьями; Artificial Intelligence as a Service (AIaaS) для анализа поведения и здоровья пчел; временное использование незагружаемого ПО для аналитики пчеловодства; исследовательские и научно-аналитические услуги в пчеловодстве.
