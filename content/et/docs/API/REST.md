Üldiseks kasutamiseks soovitame kasutada meie [GraphQL](GraphQL.md).
Ääreseadmete jaoks pakume mikroteenusepõhiseid versioonipõhiseid REST API-sid.

REST API dokumentatsioon genereeritakse nüüd teenuste enda OpenAPI spetsifikatsioonidest: [`telemetry-api`](https://github.com/Gratheon/telemetry-api) ja [`gate-video-stream`](https://github.com/Gratheon/gate-video-stream). Sisseehitatud Swagger UI võimaldab teenuseid vahetada, päringuid proovida, cURL näiteid vaadata ning Postman, Bruno või Insomnia kogusid alla laadida.
