title: 🗂️ REST APIs
---
Üldiseks kasutamiseks soovitame kasutada meie [GraphQL](GraphQL.md).
Ääreseadmete jaoks pakume mikroteenusepõhiseid versioonipõhiseid REST API-sid.

REST API dokumentatsioon on nüüd hostitud mikroteenustes endis, nii et dokumentatsioon püsib seotud teenuste OpenAPI lepingutega. OpenAPI URL-i saab importida Postmani, Brunosse või Insomniasse client collectionite genereerimiseks; Swagger UI-s saab kopeerida ka cURL näiteid.

- [Telemetry API Swagger UI](https://telemetry.gratheon.com/docs/)
- [Telemetry API OpenAPI JSON](https://telemetry.gratheon.com/openapi.json)
- [Gate Video Stream Swagger UI](https://video.gratheon.com/docs/) — sõltub `video.gratheon.com` saadavusest
- [Gate Video Stream OpenAPI JSON](https://video.gratheon.com/openapi.json)
