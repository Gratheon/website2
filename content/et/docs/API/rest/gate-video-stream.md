Kasuta seda REST API-t, kui rakendus vajab taru sissepääsukaamera salvestuste jaoks taasesitatavaid HLS-esitusloendeid. API tagastab M3U8-esitusloendeid, mis suunavad videopleierid salvestatud striimisegmentideni.
